# Wakama – Solana Foundation (2-week milestone)

This document describes the minimal end-to-end flow we delivered for the 2-week milestone.

## 1. Repositories

Public / visible repos:

1. **wakama-dashboard**
   - Next.js dashboard
   - Page: `/now-playing`
   - Reads `public/now.json` (snapshot)
   - Shows Solana-like cards + table
   - Env: `NEXT_PUBLIC_BASE_URL`, `NEXT_PUBLIC_IPFS_GATEWAY`, `NEXT_PUBLIC_RPC`

2. **wakama-rwa-templates**
   - JSON templates for Wakama RWA
     - `wakama.sensor.record`
     - `wakama.sensor.batch`
     - `wakama.coop.delivery`
   - Tools:
     - `tools/gen-coop.cjs` → generates multiple coop deliveries for demo
     - `tools/make-receipt.cjs` → turns CSV/JSON into a receipt-compatible JSON
   - README explains how to publish to the dashboard

3. **wakama-oracle-firmware**
   - ESP32 demo firmware
   - Generates Wakama-shaped JSON with real site metadata:
     - zone: `Bouake`
     - field: `KouassiKongokro`
     - coop: `Etra`
   - Arduino-friendly (`src/main.ino`, `src/config.h`)
   - Can later POST to an ingest URL

Private / backend repos:

4. **wakama-oracle-publisher**
   - CLI that takes a JSON batch from `ingest/` or from the generator
   - Uploads it to **Pinata (IPFS)**
   - Then sends a **Solana Devnet tx** with the JSON memo
   - Then writes a **receipt** to `receipts/`
   - Then rebuilds the dashboard snapshot:
     - `npm run export_now` → writes to `../wakama-dashboard/public/now.json`
   - `.env.example` provided

5. **wakama-oracle-ingest**
   - Local ingest/batcher (JSON → batches) used by the publisher

6. **wakama-docs**
   - This file
   - Short specs and quickstarts
   - Used to report to Solana Foundation

7. **wakama-oracle-anchor** (WIP)
   - Anchor program stub (DataBatch event)
   - Out of scope for the 2-week milestone because of toolchain issues
   - Documented as “next step”

## 2. End-to-end flow (delivered)

1. **Device / source**  
   - ESP32 (simulated) or JSON from `wakama-rwa-templates`

2. **Template / normalize**  
   - JSON is in Wakama format (sensor or coop delivery)
   - Example: `templates/sensor_batch-etra-bouake.json`

3. **Publish**  
   - In `wakama-oracle-publisher`:
     ```bash
     node src/publish.cjs ingest/sensor_batch-etra-bouake.json
     npm run export_now
     ```
   - This does:
     - IPFS → Pinata
     - Solana Devnet tx (memo contains `{cid,sha256,...}`)
     - write receipt
     - update dashboard snapshot

4. **Dashboard**  
   - In `wakama-dashboard`:
     - `/now-playing` shows the new line
     - Columns: CID (IPFS), Tx (Devnet), file name, SHA-256, timestamp, source, record type

This is exactly the flow required for the “2 weeks” milestone: **local JSON → IPFS → Solana Devnet → dashboard.**

## 3. Known limitations (documented)

- Anchor program not shipped yet (toolchain unstable on this machine).
- Vercel may show an earlier snapshot; the latest snapshot is always the one generated by `npm run export_now` from `wakama-oracle-publisher`.
- Firmware currently generates **simulated** values; wiring doc is provided to connect real sensors (DHT22 / DS18B20 / soil).
